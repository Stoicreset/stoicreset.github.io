# Stoic Reset public site (GitHub Pages)

Static pages only. Nothing here connects to the Stoa PC, the NAS or the Mac Studio.

| Path | What it is |
|---|---|
| `/` | Link in bio (fill in the TikTok and Instagram `data-href` values in index.html) |
| `/terms` | Terms of Service for the TikTok/Instagram app |
| `/privacy` | Privacy Policy |
| `/tiktok-connect` | TikTok sign-in return page. Forwards the owner's browser to the private Stoa address carried in `state`, only if it is https on a `.ts.net` name. |
| `tiktok*.txt` | TikTok's URL-verification file, added when TikTok issues it |

Published at https://stoicreset.github.io from the repo `stoicreset/stoicreset.github.io` (flat files, uploaded through GitHub's web uploader).
